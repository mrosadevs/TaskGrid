# Contributing to TaskGrid

## Branch strategy
- `main`: stable releases
- `dev`: default branch; feature branches branch from here

## Workflow
1. `git checkout -b feature/short-description`
2. Commit small, clear messages
3. Push and open a PR to `dev`
4. Require 1 review from a teammate
5. Squash & merge

## Commit style
- feat: add calendar week view
- fix: correct date parsing
- chore: update CI
